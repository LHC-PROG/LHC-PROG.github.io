# LHC-PROG · 研究与实践

沿溪流前进的三维林间主页，依次展示技术能力、X-VLA 研究、3D 视觉、医学影像处理与 MiniCamp 活动。新增方向以关注和探索为表述，MiniCamp 介绍活动本身。

正文直接叠在场景上，使用轻微字边阴影与统一场景调色保证可读性，不绘制局部黑色模糊遮罩。空间中的浅雾、昼夜与风动独立保留。

## 本地查看

双击「预览主页.bat」，或运行 `node preview.cjs`，浏览器打开 http://127.0.0.1:8770/ 。无需安装依赖。WebGL 模块需通过本地服务加载。

个人内容统一编辑 `profile.js`。保持研究结论的适用范围、方法名称与活动角色准确；公开修改前检查变更。

## 文件

- `index.html` / `style.css`：版式、艺术标题、阅读层与入口。
- `content.js` / `profile.js`：个人内容与阅读交互。
- `journey.js`：连续场景、滚动镜头、地形、风与昼夜。
- `botany.js`：树木、草叶、石块、溪水与云的颗粒构建。
- `atmosphere.js`：浅雾、光尘与振翅小虫。
- `assets/ecology.js`：森林中的齐腰灌木、平野与山丘上的草花、飞鸟、跳跃兔子、松鼠与蝴蝶，沿用场景的颗粒绘画语言；结尾夕阳使用流动空气散射与暖色辉光，并在正文一侧衰减亮度。
- `assets/`：原创植物插画、静态备用图、本地字体和 Three.js；许可证与来源见各目录。

小屏降低场景密度与帧率；页面不可见时暂停。系统偏好减少动态效果时关闭自动动画，滚动仍可切换观察位置。无 WebGL 时保留备用图与完整正文。

原生标注入口：在支持标注的应用内浏览器打开 https://lhc-prog.github.io/?edit=1 。进入标注模式时暂停环境动画。

GitHub Pages 通过 `.github/workflows/pages.yml` 发布 main 分支的网页与素材。推送后自动部署，也可在 Actions 的「Publish portfolio」中手动运行。该流程使用独立队列，避免旧的 Pages 重试阻塞；发布包只包含网站运行文件。

GitHub Profile 使用同一世界导出的动态封面，两端保持一致。
